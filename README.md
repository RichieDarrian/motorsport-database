\# Database Project



\*\*Project Case: CarWonders Racing Partnerships Database\*\*



This document describes the requirements behind the accompanying `.sql` file: the business case, the entities/constraints the schema enforces, and the queries the script implements.



\---



\## Case



\*\*CarWonders\*\* is the biggest car dealer company in the world. Jose, President Director of CarWonders, is working to expand the company. Since CarWonders specializes in automotive and car sales, the company wants to build connections and collaborations with race event organizers. CarWonders currently holds partnerships with \*\*Le Mans 24 Hours\*\* and the \*\*Monaco Grand Prix\*\*.



Jose has already designed the Entity Relationship Diagram (ERD) for the database to ensure it is easy to use. However, Jose is unsure how to insert data into the database. The goal of this project is to help Jose populate the database so CarWonders can operate the system fully.



\---



\## Database Requirements



Each master entity uses a fixed-format identification number, where `X` denotes a digit between 0 to 9.



| Entity | ID Format | Notes |

|---|---|---|

| Country | `CYXXX` | Supported countries: Argentina, Australia, Belgium, Brazil, Canada, China, England, France, Germany, Greece, Italy, Indonesia, Japan, Netherlands, Portugal, Russia, Saudi Arabia, Spain, South Korea, and United States. All must be inserted. |

| Circuit | `CCXXX` | Must include the circuit name. |

| Brand | `BRXXX` | Existing partners: Aston Martin, Bugatti, and Porsche. New brands may also be added. |

| Car | `CRXXX` | Must include car name and car power. |

| Sponsor | `SPXXX` | Existing sponsors: Bridgestone, Loro Piana, Heineken, and Rolex. Other sponsors may also be inserted. |

| Event | `EVXXX` | Existing events: Le Mans 24 Hours and Monaco Grand Prix. New events may also be created. |

| Racer | `RCXXX` | Must include full name, age, address, and gender. |



\### Schema (DDL) Constraints



\- Car power must be ≥ 300 and ≤ 1000.

\- Racer name must consist of both a first name and a last name.

\- Racer gender must be either "Male" or "Female".

\- Each racer must have at least 3 different cars.

\- Each brand must have 3 to 5 cars.

\- Each event must have at least 15 racers.

\- Each event must be supported by at least 3 different sponsors.



\### Data Population (DML) Rules



\- Every master table must be filled with 25 or more records, except the Country table.

\- The EventHeader table must be filled with 15 or more records.

\- The volume of all other tables must follow the constraints above.

\- A separate DML query must simulate the event process for race registration and sponsor registration, distinct from the initial data-population query.

\## Queries Implemented



The script implements the following 20 queries and views.



1\. Display the international sponsor code and the total number of events for sponsors associated with events held in Australia. The international sponsor code is generated by concatenating 'ISC' with the last three digits of the sponsor ID and the ASCII value of the sponsor's name, while also retrieving the sponsor's name and counting the total number of events each sponsor has been involved in, grouped by sponsor name and sponsor ID.

2\. Display the Aston x Bridgestone Event Racers, racer names who have Aston Martin cars and are joining events sponsored by Bridgestone.

3\. Increase the car power by 20% for cars that have power less than 550.

4\. Display the events sponsored by Loro Piana and Heineken, sorted by earliest event first, with the event date formatted like 'October 26, 2017'.

5\. Display Racer Name, Country Name (the racer's origin country), and Number Sponsored (count of racers joining events sponsored by Rolex, where the count is odd).

6\. Display the race events and their circuit names for events held in Germany and France, replacing 'Hours' with 'Fantastical' in event names that contain 'Hours', while excluding events occurring between the 16th and 31st of the month.

7\. Display Event Month (month of the event date) and Existing Event (the event count combined with 'event(s)') for events held before September.

8\. Display car name, brand name, and Total Used (count of times a car was chosen by a racer), for each car used between 1 and 3 times.

9\. Display Secret Brand Code (three characters reversed from the middle of the brand name), Brand Name, and the Highest Rated HP (max car power for that brand) for every brand from Italy.

10\. Display the Event Name and Candidates (racer count with the word 'Participants' appended).

11\. Delete the event sponsor record where the sponsor is KPMG.

12\. Display a list of racers whose names contain both the letters 'c' and 'w', along with their respective country names.

13\. Display the Event Id (replacing the 'EV' prefix with the first and last character of the first word of the circuit name), Event Name, and the origin of the circuit, for every event whose name contains "Hours".

14\. Display the Car's Nationality (uppercase first three letters of the country name combined with the car name, brand name removed) and the Car Redeem Code (reversed brand name with the last two characters of the car name appended, in lowercase).

15\. Create a view named `IndonesianRacers` that retrieves the names of racers from Indonesia, along with their total number of cars driven and average car power (formatted with 'HP'), grouped by racer name.

16\. Create a view named `Past5MonthEvent` that displays the event name and Racer Participation for each event held 5 months ago from the current date.

17\. Display the participant code, racer name, and racer origin for racers driving Bugatti cars, where the participant code replaces 'RC' in the racer's ID with the lowercase initials of their first and last names.

18\. Display the race events along with the circuit name for events featuring Porsche or Bugatti cars, using a CASE statement to modify the event name: replace 'Grand Prix' with 'Championship' plus the circuit name for events ending in 'Grand Prix'; replace 'Hours' with part of the circuit name for events ending in 'Hours'; otherwise replace the first word of the event name with 'Super'.

19\. Display the credentials code for racers based on performance and car details, combining the first letter of the racer's name, the first letter of the car's name, the last letter of the event name, the sum of the day and month of the event date, and two initials from the racer's name, along with the racer's full name with a two-letter country code, the car name, and total events participated. One part filters racers in the "Monaco Grand Prix" with cars named using three spaces and more than 10 events; the other filters racers in the "Le Mans 24 Hours" with two-word car names and fewer than 10 events.

20\. Display the top five international participants by car strength (average car power), formatting the racer's name with their country in single quotes, grouped by racer name and country, ordered by car strength descending.
